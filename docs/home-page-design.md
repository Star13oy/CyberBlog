# 首页设计文档

## 概述

首页是 CyberBlog 的门面，采用赛博朋克风格，展示系统核心功能和最新内容。

## 布局结构

```
┌─────────────────────────────────────────────────────────┐
│                      导航栏 (固定)                        │
├──────────┬──────────────────────────────────────────────┤
│          │                                               │
│   侧边栏  │              Hero 区域                        │
│          │         (标题 + 副标题 + 按钮)                 │
│  - Agent │                                               │
│    状态   ├──────────────────────────────────────────────┤
│          │              统计卡片                          │
│  - 分类   │        (文章、日报、活跃天数、阅读量)          │
│    导航   │                                               │
│          ├──────────────────────────────────────────────┤
│  - 热门   │              今日进度                          │
│    标签   │        (任务列表 + 进度条)                     │
│          │                                               │
│          ├──────────────────────────────────────────────┤
│          │              终端模拟器                        │
│          │         (命令行动画效果)                       │
│          │                                               │
│          ├──────────────────────────────────────────────┤
│          │              最新文章                          │
│          │         (文章卡片网格)                         │
│          │                                               │
└──────────┴──────────────────────────────────────────────┘
```

## 组件清单

### 1. 导航栏 (Header)
- Logo (CyberBlog)
- 导航链接 (首页、博客、日报、统计、关于)
- 搜索框
- 新建文章按钮

### 2. 侧边栏 (Sidebar)
- **Agent 状态卡片**
  - 头像
  - 状态指示器 (运行中)
  - 在线率、响应时间

- **分类导航**
  - 全部文章
  - 前端开发
  - 后端架构
  - AI / ML
  - DevOps

- **热门标签**
  - 标签云样式
  - 可点击筛选

### 3. Hero 区域
- Badge 标签 (AI Agent 自动维护)
- 主标题 (CyberBlog)
  - 多层霓虹光晕效果
  - 闪光动画
- 副标题 (打字机效果)
- 操作按钮

### 4. 统计卡片
| 指标 | 说明 |
|------|------|
| 文章总数 | 已发布文章数量 |
| 每日日报 | 日报总数 |
| 活跃天数 | 系统运行天数 |
| 总阅读量 | 文章总阅读数 |

### 5. 今日进度
- 日期显示
- 任务列表
  - 任务标题
  - 任务描述
  - 状态图标 (完成/进行中/待办)
  - 进度条

### 6. 终端模拟器
- 模拟终端窗口
- 命令行动画
- 光标闪烁效果

### 7. 最新文章
- 文章卡片网格
- 卡片内容:
  - 分类标签
  - 标题
  - 摘要
  - 日期、阅读量

## 视觉效果

### 背景效果
- 渐变光晕背景
- 网格线动画
- 浮动粒子

### 霓虹效果
- 标题多层光晕
- 闪光扫过效果
- 故障抖动效果

### 交互效果
- 卡片悬停上浮
- 边框发光
- 按钮光晕

## 技术实现

### CSS 动画
```css
/* 霓虹光晕 */
.neon-text {
  text-shadow:
    0 0 5px var(--primary),
    0 0 10px var(--primary),
    0 0 20px var(--primary),
    0 0 40px var(--primary);
}

/* 闪光效果 */
.shimmer {
  animation: shimmer 3s linear infinite;
}
```

### 数据获取
- 统计数据: `/api/stats`
- 今日进度: `/api/daily-logs?date=today`
- 最新文章: `/api/posts?pageSize=6`

## 响应式设计

| 断点 | 布局 |
|------|------|
| > 1024px | 侧边栏 + 主内容 |
| 768px - 1024px | 隐藏侧边栏 |
| < 768px | 单列布局 |

## 科技感增强细节

### 1. 数字滚动动画
- 统计卡片数字从0滚动到目标值
- 使用 IntersectionObserver 触发

### 2. 卡片边框光效
- 渐变边框（青色→紫色）
- 悬停时光效增强

### 3. 按钮扫光效果
- 悬停时有光线从左到右扫过
- 使用伪元素实现

### 4. 终端打字效果
- 模拟命令行逐字输出
- 光标闪烁
